Zwischenablage
- Hilfe
(Hilfe durchsuchen)
Che Windows-Zwischenablage ermöglicht den Austausch von Bildern zwischen diesem Programm und anderen Windows-Programmen. Mit den Funktionen Ausschneiden und Kopieren Im
Pulldown-Menü Bearbeiten können Sia eine oder mehrere Seiten aus der Seitenübersicht In die Zwischenablage übernehmen, mit der Funktion Einfügen können Sie Seiten aus der
Zwischenablage in die Seitenübersicht einfügen
Beachten Sie jedoch folgende Einschränkung:
Das Betriebssystem bietet leider keine kompatible Möglichkeit, mehr als eine Seite gleichzeitig in die allgemeine Windows-Zwischenablage zu übernehmen. Deshalb Wird von anderen Programmen
jeweils nur die erste der von "Scanner-Interface" in die Zwischenablage kopierten Seitan übernommen. daim Kopieren und Einfügen mehrerer Seitan innerhalb von "Scanner-Interface" gilt diese
Einschränkung nicht, da das Programm eine leistungsfähigere interne Zwischenablage verwendet. Diese Wird allerdings bei Programmende gelöscht, so dass beim nachsten Programmstalt nur der
Inhalt der allgemeinen Windows-Zwischenablage (max. 1 Seite) ven,vendet Wird.

MAPI
Beschreibung
- Hilfe
(Hilfe durchsuchen)
Das MAPI (Messaging Application Programmng Interface) in Microsoft Windows ist ein standardisiertes Interface zwischen E-Mailprogramman und anderer Software. In Verbindung mit einem MAPI-
kompatiblen E-Mailprogramm kann "Grewe Scanner-Intefface" aus eingelesenen Seiten eine E-Mail erzeugen.
So erkennen Sie, ob ein MAPI-kompatibles E-Mailprogramm vorhanden ist:
Wenn "Grewe Scanner-Intalface" kein passendes E-Mailprogramm findet, gibt es eine entsprechende Fehlermeldung aus bei dem Versuch, eine E-Mail zu erzeugen. Lesen Sie in diesem Fall in der
Anleitung Ihres E-Mailprogramms nach, ob und Wie Sie dieses als MAPI-kompatlbel konfigurieren können.
Hinweis zu "Windows 7":
Mit diesem Betriebssystem wird standardmäßig kein E-Mailprogramm installiert. Zur nachtraglichen Installation bietet Microsoft das Programm "Windows Live Mail" an.

Che Still-Image-Schnittstelle in Microsoft Windows ist ein standardisiertes Interface zwischen Bildeffassungsgeräten (Wie z. B. Scannern) und Bildeffassungssoftware (wie z. B. diesem Programm).
Unter anderem erlaubt es die Steuerung des Programms Über die am Scanner angebrachten Funktionstasten
Allerdings Wird diese Funktion nicht von allen Scannenreibern unterstützt. Bel fehlender Unterstützung ist die Belegung der Scanner-Funktionstasten fest im Scannenrelber vorgegeben, die Tasten
können dann nicht zur Steuerung dieses Programms verwendet werden.

WIA steht für "Windows Image Acquisition" und ist eine Softwareschnittstelle zwischen Bilderfassungsgaräten und Microsoft Windows. Die Treibersoftware moderner Scanner ist häufig mit einer
WlA-Schnittstalle ausgestattet. Windows bietet für diese Scanner eine WlA-T'uVAlN-Konvartierung an, auf die auch dieses Programm zugreift. Sie erkennen diese Scanner in der Regel an der
Zeichenfolge 'WIA-" vor dem eigentlichen Scannernamen in der Auswahlliste des Programms
